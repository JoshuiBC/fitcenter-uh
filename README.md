# FitCenter UH

Sitio web estático y responsive para FitCenter UH, con rutinas de bulking, definición y pérdida de peso, perfiles de nutricionistas, preguntas frecuentes y contacto.

## Vista local

Abre `index.html` en el navegador o inicia un servidor estático desde la raíz del proyecto.

## Antes de publicar

Reemplaza los datos demostrativos de los nutricionistas, números de WhatsApp, correo, horarios, acreditaciones, fotografías y enlaces a redes sociales por la información oficial.
